# cambodiadnsserver

Official repository for **CHM Cambodia DNS Server**, High-Performance Secure DNS, VPN Tunneling Configurations, and Client Assets.

Developed and maintained by the **CHM Cambodia DNS Team**.

## 🚀 Key Features
- **Ultra-Fast Cambodia DNS Resolvers**: Low-latency DNS forwarding optimized for Cambodia ISPs (Smart, Cellcard, Metfone).
- **DNS-over-HTTPS (DoH) & DNS-over-TLS (DoT)**: Secure, encrypted query handling with zero-logging policy.
- **Tunneling Protocols**: Comprehensive configurations for UDP Custom, BadVPN UDPGW, SlowDNS, V2Ray (VMess/VLESS), and SSH.
- **Client App Suite**: Android APK build scripts, automated zipalign, and dual-signing pipelines (v1 + v2).
- **VIP Black & Gold Design**: Luxury aesthetic branding assets and UI components.
